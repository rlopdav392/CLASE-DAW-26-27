# 🛠️ MÉTODO DE PROGRAMACIÓN

## 1️⃣ PRIMERO: HACEMOS QUE FUNCIONE

Escribimos el código necesario para resolver el problema, aunque al principio no esté perfectamente organizado.

**Objetivo:** conseguir que el programa funcione.

---

## 2️⃣ SEGUNDO: ORGANIZAMOS EL CÓDIGO

Cuando el programa funciona, lo organizamos en **funciones**.

Cada función debe encargarse de una tarea concreta.

**Objetivo:** que el código sea más claro, ordenado y fácil de mantener.

---

## 3️⃣ TERCERO: CONTROLAMOS LOS ERRORES

Comprobamos qué puede ocurrir si el usuario introduce datos incorrectos o si algo no funciona como esperamos.

Por ejemplo:

- Comprobar que se ha introducido un dato.
- Comprobar que un número está dentro de un rango.
- Comprobar que un elemento existe antes de utilizarlo.

**Objetivo:** evitar errores y hacer que el programa sea más robusto.

---

## 4️⃣ CUARTO: OPTIMIZAMOS Y MEJORAMOS ORGANIZACIÓN Y BUENAS PRÁCTICAS

Una vez que el programa funciona correctamente, buscamos formas de mejorar el código.

Por ejemplo:

- Evitar código repetido.
- Simplificar condiciones.
- Mejorar los nombres de variables y funciones. (camelCase,...)
- Utilizar métodos de arrays como `find()`, `filter()`, `map()`, etc.
- Utilizar `addEventListener()` en lugar de eventos escritos directamente en HTML como `onclick`.
- Mejorar la forma de cargar nuestro JavaScript.


Por ejemplo, en lugar de:

```html
<button onclick="saludar()">Saludar</button>
```

Podemos separar el HTML del JavaScript:

```html
<button id="btnSaludar">Saludar</button>
```

```javascript
const boton = document.querySelector("#btnSaludar");

boton.addEventListener("click", saludar);
```
