# Plantilla con `<Outlet />`: el Header una sola vez

En Figma, el equipo de diseño coloca una **instancia** del Header en cada pantalla: _Inicio_, _Producto_ y _Carrito_. Si después se cambia el componente maestro (por ejemplo, se añade el enlace _Novedades_), el cambio aparece automáticamente en todas las pantallas.

En React no hace falta escribir `<Header />` en cada vista. Con **React Router** se crea una **plantilla** (layout) que contiene el Header una sola vez, y un `<Outlet />` donde se pinta la vista que toque en cada momento.

### `Plantilla.jsx`

```jsx
import { Outlet } from "react-router-dom";
import { Header } from "./Header";

export function Plantilla() {
  return (
    <>
      <Header />{" "}
      {/* Figma: instancia de "Header", común a todas las pantallas */}
      <main>
        <Outlet /> {/* aquí se pinta Inicio, Producto o Carrito */}
      </main>
    </>
  );
}
```

### `App.jsx`

Todas las rutas que van dentro de la plantilla comparten el Header:

```jsx
import { BrowserRouter, Routes, Route } from "react-router-dom";
import { Plantilla } from "./Plantilla";
import { Inicio } from "./Inicio";
import { Producto } from "./Producto";
import { Carrito } from "./Carrito";

export function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route element={<Plantilla />}>
          <Route path="/" element={<Inicio />} />
          <Route path="/producto/:id" element={<Producto />} />
          <Route path="/carrito" element={<Carrito />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```

### Las vistas

Las vistas ya no llevan el Header, solo su propio contenido:

```jsx
export function Inicio() {
  return <section>{/* contenido de la página de inicio */}</section>;
}

export function Producto() {
  return <section>{/* ficha del producto */}</section>;
}

export function Carrito() {
  return <section>{/* productos del carrito */}</section>;
}
```

```text
FIGMA                                     REACT

Componente maestro "Header"          →    Header.jsx
Instancia en la pantalla Inicio      ┐
Instancia en la pantalla Producto    ├→   <Header /> una sola vez en Plantilla.jsx
Instancia en la pantalla Carrito     ┘    + <Outlet /> para cada vista
```

Si hay que añadir el enlace _Novedades_, se cambia **solo `Header.jsx`** y aparece en todas las vistas, igual que al editar el componente maestro en Figma. Y si mañana se crea una vista nueva dentro de la plantilla, ya tendrá el Header sin hacer nada más.
