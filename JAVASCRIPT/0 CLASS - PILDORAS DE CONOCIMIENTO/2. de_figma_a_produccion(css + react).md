# De Figma a producción (CSS + React)

Cuando pasamos un diseño de **Figma** a código, el objetivo es que **cualquier nombre que exista en Figma se pueda encontrar tal cual en el código**. Si en Figma un estilo se llama `zapatillasHerrero/Color/Texto/Principal`, en CSS debe existir una variable que se llame igual (adaptada a la sintaxis de CSS): `--zapatillas-herrero-color-texto-principal`.

Así, diseño y desarrollo hablan el mismo idioma: si alguien cambia un estilo en Figma, sabemos exactamente qué línea de CSS hay que tocar.

| Figma                                   | Desarrollo                        |
| --------------------------------------- | --------------------------------- |
| Estilo de color                         | Variable CSS                      |
| Estilo de texto                         | Variables CSS + clase CSS         |
| Componente maestro                      | Componente React                  |
| Instancia                               | Uso del componente (`<Header />`) |
| Propiedad de variante (`Tipo=Primario`) | Prop de React (`tipo="primario"`) |

---

## 1. Cómo se organizan los estilos en Figma

Como mínimo, en Figma se crean **estilos de color** y **estilos de texto**. Todos empiezan por el nombre de la marca, igual que Google usa `M3/...` en Material Design. Así los estilos de la marca quedan agrupados y no se mezclan con los de otros kits o librerías.

En Figma **las carpetas se crean con la barra `/` en el nombre del estilo**. Al crear un estilo llamado `zapatillasHerrero/Color/Texto/Principal`, Figma crea automáticamente las carpetas `zapatillasHerrero` → `Color` → `Texto` y dentro pone el estilo `Principal`. No hay que crear las carpetas aparte.

### Estructura de carpetas

```text
zapatillasHerrero/
├── Color/
│   ├── Principal/              (colores principales, sacados del logo)
│   │   ├── Primario
│   │   └── Secundario
│   ├── Texto/
│   │   ├── Principal
│   │   ├── Secundario
│   │   └── Sobre-primario      (texto encima de un fondo de color primario)
│   ├── Fondo/
│   │   ├── Principal
│   │   └── Superficie          (tarjetas, cajas)
│   ├── Borde/
│   │   └── Principal
│   └── Estado/
│       ├── Error
│       ├── Exito
│       └── Aviso
│
└── Tipografia/
    ├── Titulo/
    │   ├── Grande
    │   ├── Mediano
    │   └── Pequeno
    ├── Cuerpo/
    │   ├── Grande
    │   └── Mediano
    └── Etiqueta/               (botones, menús, textos cortos)
        └── Mediano
```

### Reglas al poner nombres en Figma

1. **Nombrar por uso, no por valor.** `Color/Principal/Primario` sí, `Color/Azul` no. Si mañana el azul pasa a ser verde, el nombre sigue sirviendo.
2. **Sin tildes ni ñ.** Así el nombre se copia igual en CSS: `Tipografia`, `Pequeno`, `Exito`.
3. **Pocos niveles.** Marca + tipo + grupo + nombre es suficiente.
4. **La raíz siempre escrita igual:** `zapatillasHerrero`, nunca `ZapatillasHerrero` ni `zapatillas herrero`.

## 2. Cómo se traduce un nombre de Figma a CSS

Siempre se aplica la misma regla:

1. Empezar con `--`
2. La marca en minúsculas y separada con guion: `zapatillasHerrero` → `zapatillas-herrero`
3. El resto en minúsculas
4. Cambiar cada `/` por `-`

| Nombre en Figma                                | Nombre en CSS                                     |
| ---------------------------------------------- | ------------------------------------------------- |
| `zapatillasHerrero/Color/Principal/Primario`   | `--zapatillas-herrero-color-principal-primario`   |
| `zapatillasHerrero/Color/Texto/Sobre-primario` | `--zapatillas-herrero-color-texto-sobre-primario` |
| `zapatillasHerrero/Tipografia/Titulo/Grande`   | `--zapatillas-herrero-tipografia-titulo-grande-…` |

No se inventan nombres nuevos: **se lee el nombre de Figma y se escribe en formato CSS**.

## 3. Estilos de color → variables CSS

Un estilo de color es **un solo valor**, así que se convierte en **una variable CSS**. Al lado de cada variable va un comentario con su nombre exacto en Figma.

> Los valores de color son de ejemplo. Hay que sustituirlos por los que estén definidos en Figma.

```css
:root {
  /* ===== zapatillasHerrero/Color ===== */

  /* Principal */
  --zapatillas-herrero-color-principal-primario: #0066ff; /* zapatillasHerrero/Color/Principal/Primario */
  --zapatillas-herrero-color-principal-secundario: #ff6b00; /* zapatillasHerrero/Color/Principal/Secundario */

  /* Texto */
  --zapatillas-herrero-color-texto-principal: #1d1b20; /* zapatillasHerrero/Color/Texto/Principal */
  --zapatillas-herrero-color-texto-secundario: #5f5f66; /* zapatillasHerrero/Color/Texto/Secundario */
  --zapatillas-herrero-color-texto-sobre-primario: #ffffff; /* zapatillasHerrero/Color/Texto/Sobre-primario */

  /* Fondo */
  --zapatillas-herrero-color-fondo-principal: #ffffff; /* zapatillasHerrero/Color/Fondo/Principal */
  --zapatillas-herrero-color-fondo-superficie: #f5f5f7; /* zapatillasHerrero/Color/Fondo/Superficie */

  /* Borde */
  --zapatillas-herrero-color-borde-principal: #d9d9de; /* zapatillasHerrero/Color/Borde/Principal */

  /* Estado */
  --zapatillas-herrero-color-estado-error: #d32f2f; /* zapatillasHerrero/Color/Estado/Error */
  --zapatillas-herrero-color-estado-exito: #2e7d32; /* zapatillasHerrero/Color/Estado/Exito */
  --zapatillas-herrero-color-estado-aviso: #ed6c02; /* zapatillasHerrero/Color/Estado/Aviso */
}
```

## 4. Estilos de texto → variables CSS + clase

Un estilo de texto **agrupa varias propiedades**. Al seleccionar un estilo de texto en Figma se ven:

```text
FIGMA — zapatillasHerrero/Tipografia/Titulo/Grande

Font          Roboto
Weight        Bold (700)
Size          40
Line height   48
```

Por eso cada estilo de texto se convierte en **una variable por propiedad**. El nombre de la variable es el nombre del estilo en Figma más la propiedad al final:

| Propiedad en Figma | Final de la variable CSS |
| ------------------ | ------------------------ |
| Font               | `-font`                  |
| Weight             | `-weight`                |
| Size               | `-size`                  |
| Line height        | `-line-height`           |

> Los valores tipográficos son de ejemplo. Hay que sustituirlos por los que estén definidos en Figma.

```css
:root {
  /* ===== zapatillasHerrero/Tipografia ===== */

  /* zapatillasHerrero/Tipografia/Titulo/Grande */
  --zapatillas-herrero-tipografia-titulo-grande-font: "Roboto", sans-serif;
  --zapatillas-herrero-tipografia-titulo-grande-weight: 700;
  --zapatillas-herrero-tipografia-titulo-grande-size: 40px;
  --zapatillas-herrero-tipografia-titulo-grande-line-height: 48px;

  /* zapatillasHerrero/Tipografia/Titulo/Mediano */
  --zapatillas-herrero-tipografia-titulo-mediano-font: "Roboto", sans-serif;
  --zapatillas-herrero-tipografia-titulo-mediano-weight: 700;
  --zapatillas-herrero-tipografia-titulo-mediano-size: 32px;
  --zapatillas-herrero-tipografia-titulo-mediano-line-height: 40px;

  /* zapatillasHerrero/Tipografia/Titulo/Pequeno */
  --zapatillas-herrero-tipografia-titulo-pequeno-font: "Roboto", sans-serif;
  --zapatillas-herrero-tipografia-titulo-pequeno-weight: 700;
  --zapatillas-herrero-tipografia-titulo-pequeno-size: 24px;
  --zapatillas-herrero-tipografia-titulo-pequeno-line-height: 32px;

  /* zapatillasHerrero/Tipografia/Cuerpo/Grande */
  --zapatillas-herrero-tipografia-cuerpo-grande-font: "Roboto", sans-serif;
  --zapatillas-herrero-tipografia-cuerpo-grande-weight: 400;
  --zapatillas-herrero-tipografia-cuerpo-grande-size: 18px;
  --zapatillas-herrero-tipografia-cuerpo-grande-line-height: 28px;

  /* zapatillasHerrero/Tipografia/Cuerpo/Mediano */
  --zapatillas-herrero-tipografia-cuerpo-mediano-font: "Roboto", sans-serif;
  --zapatillas-herrero-tipografia-cuerpo-mediano-weight: 400;
  --zapatillas-herrero-tipografia-cuerpo-mediano-size: 16px;
  --zapatillas-herrero-tipografia-cuerpo-mediano-line-height: 24px;

  /* zapatillasHerrero/Tipografia/Etiqueta/Mediano */
  --zapatillas-herrero-tipografia-etiqueta-mediano-font: "Roboto", sans-serif;
  --zapatillas-herrero-tipografia-etiqueta-mediano-weight: 500;
  --zapatillas-herrero-tipografia-etiqueta-mediano-size: 14px;
  --zapatillas-herrero-tipografia-etiqueta-mediano-line-height: 20px;
}
```

Para no repetir las cuatro propiedades cada vez que se usa un estilo, se crea además **una clase por estilo de texto**, con el mismo nombre (sin el `--`):

```css
/* zapatillasHerrero/Tipografia/Titulo/Grande */
.zapatillas-herrero-tipografia-titulo-grande {
  font-family: var(--zapatillas-herrero-tipografia-titulo-grande-font);
  font-weight: var(--zapatillas-herrero-tipografia-titulo-grande-weight);
  font-size: var(--zapatillas-herrero-tipografia-titulo-grande-size);
  line-height: var(--zapatillas-herrero-tipografia-titulo-grande-line-height);
}

/* zapatillasHerrero/Tipografia/Cuerpo/Mediano */
.zapatillas-herrero-tipografia-cuerpo-mediano {
  font-family: var(--zapatillas-herrero-tipografia-cuerpo-mediano-font);
  font-weight: var(--zapatillas-herrero-tipografia-cuerpo-mediano-weight);
  font-size: var(--zapatillas-herrero-tipografia-cuerpo-mediano-size);
  line-height: var(--zapatillas-herrero-tipografia-cuerpo-mediano-line-height);
}

/* zapatillasHerrero/Tipografia/Etiqueta/Mediano */
.zapatillas-herrero-tipografia-etiqueta-mediano {
  font-family: var(--zapatillas-herrero-tipografia-etiqueta-mediano-font);
  font-weight: var(--zapatillas-herrero-tipografia-etiqueta-mediano-weight);
  font-size: var(--zapatillas-herrero-tipografia-etiqueta-mediano-size);
  line-height: var(
    --zapatillas-herrero-tipografia-etiqueta-mediano-line-height
  );
}

/* (igual para Titulo/Mediano, Titulo/Pequeno y Cuerpo/Grande) */
```

## 5. Componente maestro de Figma → componente React

Un **componente maestro** es una pieza que se diseña una sola vez y se repite en muchas pantallas. El ejemplo más claro es el **Header**: aparece igual en la página de inicio, en la ficha de producto y en el carrito.

### En Figma

El equipo de diseño crea un componente maestro llamado **Header** con:

- El logo de Zapatillas Herrero
- Un menú con los enlaces _Inicio_, _Hombre_, _Mujer_ y _Ofertas_
- Un enlace al carrito

Al seleccionar cada parte del Header, en el panel de la derecha se ve qué estilos usa:

```text
FIGMA — componente Header

Header (contenedor)
  Fill          →  zapatillasHerrero/Color/Fondo/Principal
  Stroke        →  zapatillasHerrero/Color/Borde/Principal    (línea inferior)

Enlaces del menú
  Text style    →  zapatillasHerrero/Tipografia/Etiqueta/Mediano
  Fill          →  zapatillasHerrero/Color/Texto/Principal

Enlace "Carrito"
  Text style    →  zapatillasHerrero/Tipografia/Etiqueta/Mediano
  Fill          →  zapatillasHerrero/Color/Principal/Primario
```

### CSS

```css
/* Componente: Header */
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 16px 32px;
  background-color: var(--zapatillas-herrero-color-fondo-principal); /* Fill */
  border-bottom: 1px solid var(--zapatillas-herrero-color-borde-principal); /* Stroke */
}

.header__logo {
  height: 32px;
}

.header__menu {
  display: flex;
  gap: 24px;
}

/* Enlaces del menú */
.header__enlace {
  color: var(--zapatillas-herrero-color-texto-principal); /* Fill */
  text-decoration: none;
}

/* Enlace "Carrito" */
.header__carrito {
  color: var(--zapatillas-herrero-color-principal-primario); /* Fill */
  text-decoration: none;
}
```

### `Header.jsx`

En React se crea un componente con el **mismo nombre** que el componente maestro de Figma:

```jsx
import "./estilos.css";
import logo from "./logo-zapatillas-herrero.svg";

// Figma: componente maestro "Header"
export function Header() {
  return (
    <header className="header">
      <img className="header__logo" src={logo} alt="Zapatillas Herrero" />

      <nav className="header__menu">
        {/* Text style: zapatillasHerrero/Tipografia/Etiqueta/Mediano */}
        <a
          className="header__enlace zapatillas-herrero-tipografia-etiqueta-mediano"
          href="/"
        >
          Inicio
        </a>
        <a
          className="header__enlace zapatillas-herrero-tipografia-etiqueta-mediano"
          href="/hombre"
        >
          Hombre
        </a>
        <a
          className="header__enlace zapatillas-herrero-tipografia-etiqueta-mediano"
          href="/mujer"
        >
          Mujer
        </a>
        <a
          className="header__enlace zapatillas-herrero-tipografia-etiqueta-mediano"
          href="/ofertas"
        >
          Ofertas
        </a>
      </nav>

      <a
        className="header__carrito zapatillas-herrero-tipografia-etiqueta-mediano"
        href="/carrito"
      >
        Carrito
      </a>
    </header>
  );
}
```

El componente **no tiene ningún valor de color ni de tipografía escrito a mano**. Solo usa los nombres que vienen de Figma.

```text
FIGMA (panel de propiedades)                                       CSS / REACT

Header      Fill    zapatillasHerrero/Color/Fondo/Principal     →  var(--zapatillas-herrero-color-fondo-principal)
Header      Stroke  zapatillasHerrero/Color/Borde/Principal     →  var(--zapatillas-herrero-color-borde-principal)
Enlaces     Text    zapatillasHerrero/Tipografia/Etiqueta/Mediano → .zapatillas-herrero-tipografia-etiqueta-mediano
Enlaces     Fill    zapatillasHerrero/Color/Texto/Principal     →  var(--zapatillas-herrero-color-texto-principal)
Carrito     Fill    zapatillasHerrero/Color/Principal/Primario  →  var(--zapatillas-herrero-color-principal-primario)
```

## 6. La instancia de Figma → uso del componente

En Figma, el equipo de diseño coloca una **instancia** del Header en cada pantalla: _Inicio_, _Producto_ y _Carrito_. Si después se cambia el componente maestro (por ejemplo, se añade el enlace _Novedades_), el cambio aparece automáticamente en todas las pantallas.

En React pasa exactamente lo mismo. Cada vista usa `<Header />`:

### `Inicio.jsx`

```jsx
import { Header } from "./Header";

export function Inicio() {
  return (
    <>
      <Header />
      <main>{/* contenido de la página de inicio */}</main>
    </>
  );
}
```

### `Producto.jsx`

```jsx
import { Header } from "./Header";

export function Producto() {
  return (
    <>
      <Header />
      <main>{/* ficha del producto */}</main>
    </>
  );
}
```

### `Carrito.jsx`

```jsx
import { Header } from "./Header";

export function Carrito() {
  return (
    <>
      <Header />
      <main>{/* productos del carrito */}</main>
    </>
  );
}
```

```text
FIGMA                                     REACT

Componente maestro "Header"          →    Header.jsx  (se escribe una vez)
Instancia en la pantalla Inicio      →    <Header /> en Inicio.jsx
Instancia en la pantalla Producto    →    <Header /> en Producto.jsx
Instancia en la pantalla Carrito     →    <Header /> en Carrito.jsx
```

Si hay que añadir el enlace _Novedades_, se cambia **solo `Header.jsx`** y aparece en las tres vistas, igual que al editar el componente maestro en Figma.

## 7. Las variantes de Figma → props de React

En Figma hay un componente **Boton** con una propiedad de variante llamada `Tipo`, con dos valores: `Primario` y `Secundario`. Cada variante usa estilos de la estructura anterior:

```text
FIGMA — componente Boton

Tipo=Primario
  Fill         →  zapatillasHerrero/Color/Principal/Primario
  Texto        →  zapatillasHerrero/Color/Texto/Sobre-primario
  Text style   →  zapatillasHerrero/Tipografia/Etiqueta/Mediano

Tipo=Secundario
  Fill         →  zapatillasHerrero/Color/Fondo/Principal
  Texto        →  zapatillasHerrero/Color/Principal/Primario
  Stroke       →  zapatillasHerrero/Color/Principal/Primario
  Text style   →  zapatillasHerrero/Tipografia/Etiqueta/Mediano
```

### CSS

```css
/* Componente: Boton */
.boton {
  padding: 12px 24px;
  border-radius: 8px;
  border: 1px solid transparent;
  cursor: pointer;
}

/* Boton → Tipo=Primario */
.boton--primario {
  background-color: var(
    --zapatillas-herrero-color-principal-primario
  ); /* Fill */
  color: var(--zapatillas-herrero-color-texto-sobre-primario); /* Texto */
}

/* Boton → Tipo=Secundario */
.boton--secundario {
  background-color: var(--zapatillas-herrero-color-fondo-principal); /* Fill */
  color: var(--zapatillas-herrero-color-principal-primario); /* Texto */
  border-color: var(--zapatillas-herrero-color-principal-primario); /* Stroke */
}
```

### `Boton.jsx`

La propiedad de variante `Tipo` de Figma se convierte en la prop `tipo`, y sus valores (`Primario`, `Secundario`) se escriben igual en minúsculas:

```jsx
import "./estilos.css";

// Figma: Boton → propiedad "Tipo" = Primario | Secundario
export function Boton({ texto, tipo = "primario" }) {
  return (
    <button
      className={`boton boton--${tipo} zapatillas-herrero-tipografia-etiqueta-mediano`}
    >
      {texto}
    </button>
  );
}
```

### Uso

```jsx
<Boton texto="Comprar" tipo="primario" />          {/* Figma: Boton, Tipo=Primario */}
<Boton texto="Ver detalles" tipo="secundario" />   {/* Figma: Boton, Tipo=Secundario */}
```

```text
FIGMA                          CSS                     REACT

Boton                     →    .boton             →    <Boton />
Boton, Tipo=Primario      →    .boton--primario   →    <Boton tipo="primario" />
Boton, Tipo=Secundario    →    .boton--secundario →    <Boton tipo="secundario" />
```

## Resumen

| En Figma                                                     | En CSS                                                                                                           | En React                                                  |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Estilo de color `zapatillasHerrero/Color/Texto/Principal`    | `--zapatillas-herrero-color-texto-principal`                                                                     | `var(--zapatillas-herrero-color-texto-principal)`         |
| Estilo de texto `zapatillasHerrero/Tipografia/Titulo/Grande` | Variables `…-font`, `…-weight`, `…-size`, `…-line-height` + clase `.zapatillas-herrero-tipografia-titulo-grande` | `className="zapatillas-herrero-tipografia-titulo-grande"` |
| Componente maestro `Header`                                  | Clases `.header`, `.header__enlace`…                                                                             | `function Header()`                                       |
| Instancia de `Header` en cada pantalla                       | —                                                                                                                | `<Header />` en cada vista                                |
| Propiedad `Tipo=Primario`                                    | `.boton--primario`                                                                                               | `tipo="primario"`                                         |

La regla de oro: **ningún valor se escribe a mano en el código si ya tiene nombre en Figma**. Se usa la variable o la clase con el mismo nombre, y se deja al lado un comentario con el nombre original de Figma.
