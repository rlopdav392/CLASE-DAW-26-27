# Convenciones de nomenclatura

| Convención               | ¿Cómo se escribe?                                                   | ¿Para qué se usa?                                                  | Ejemplo                                                                                                                                                                         |
| ------------------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **camelCase**            | Primera palabra en minúscula y las siguientes con mayúscula inicial | Variables y funciones en **JavaScript / React**                    | `const nombreUsuario = "Ana";`<br>`function obtenerUsuario() { }`                                                                                                               |
| ---                      | ---                                                                 | ---                                                                | ---                                                                                                                                                                             |
| **PascalCase**           | Todas las palabras empiezan con mayúscula                           | Componentes en **React**                                           | `function UserProfile() { }`                                                                                                                                                    |
| **snake_case**           | Palabras separadas por `_`                                          | Tablas y columnas en **SQL**                                       | `nombre_usuario`<br>`obtener_usuario`<br><br>`sql<br>CREATE TABLE usuarios (<br>    id_usuario INT,<br>    nombre_usuario VARCHAR(100),<br>    fecha_nacimiento DATE<br>);<br>` |
| **SCREAMING_SNAKE_CASE** | Todo en mayúsculas y palabras separadas por `_`                     | **Constantes**. También es correcto usar `camelCase` en JavaScript | `const MAX_INTENTOS = 3;`<br>`const maxIntentos = 3;`                                                                                                                           |
| **kebab-case**           | Palabras separadas por `-`                                          | Clases e identificadores en **CSS**                                | `.nombre-usuario { }`<br>`.obtener-usuario { }`                                                                                                                                 |
